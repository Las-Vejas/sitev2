## About Kaze

Kaze is an environmental sensor that can sense things like the temperature, humidity and light intensity.  

I designed Kaze because I wanted to get into the world of IoT and try to create my first **custom** ESPHome sensor.  

I used the ESP-32-C6-MINI module since it's pretty small in size and allowed me to make the whole sensor 44mmx80mm.  

The sensor uses the BME680 surrounding sensor to measure the required metrics.  

I made the sensor for [Hack Club's Blueprint](https://blueprint.hackclub.com) program, which funded this project.
