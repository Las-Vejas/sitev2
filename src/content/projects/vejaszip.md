## About this portfolio

I build this page as a successor of my [old portfolio](https://old.vejas.zip) since I wanted a more aesthetic and more modern page that everyone that looked at it could understand what it is about (me!).

The site is built using Astro and Tailwind, as well as Turso for DB purposes like keeping guestbook messages. I also used Shadcn/ui for some UI components like buttons. The main font is Instrument Serif and Inter is the sans-serif font.
