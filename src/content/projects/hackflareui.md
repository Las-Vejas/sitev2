## About Hackflare

Hackflare was started by me along with a couple of my buddies at [Hack Club](https://hackclub.com).

Since my friends were more eager to write the backend, which is written in Rust, I was more intrigued to develop a stunning UI for this app.

I wanted to include a very straightforward auth experience, therefore we opted to use Hack Club Auth since we have open access to it and it is relatively easy to set up.

Both the frontend and the backend is in the same repository, with the frontend in the frontend folder. I started off by picking the colours for which we picked a default dark mode and a nice orange colour. I am using the [shadcn/ui](https://github.com/shadcn-ui/ui) library to maintain a consistant design across all of the pages and the very modern design of every amazing component in the library.

The backend was written by [Nayte S](https://github.com/seradedstripes) and [Vimthusiast (Johann)](https://codeberg.org/vimthusiast) with a notable mention to [Jam06452](https://github.com/jam06452) who provided a lot of emotional support throughout the (still unfinished) development of Hackflare.
