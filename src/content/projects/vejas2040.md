## About Vejas2040

This is an RP2040 devboard that I created as my first intricate hardware project. It uses the RP2040 chip and since it was my first hard hardware project, it seems to be unable to work... So you could say this was a learning experience. 

I used KiCad to design the PCB and got them manufactured by JLCPCB.

This project was created for [Blueprint](blueprint.hackclub.com) a program by [Hack Club](https://hackclub.com), and I received funding to build my devboard.
